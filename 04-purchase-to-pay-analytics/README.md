# Purchase-to-Pay Analytics

## Objective

Analyse procurement cycle efficiency and identify transaction-level exceptions across the PR, PO and GRN process.

## Process

**Purchase Requisition → Purchase Order → Goods Receipt → Invoice → Payment**

## Analytical Tests

- PR-to-PO processing time
- PO-to-GRN receiving time
- End-to-end procurement lead time
- Open PR and PO ageing
- Long-outstanding transactions
- Duplicate transaction references
- Negative or unusual quantities
- Date inconsistencies
- Supplier lead-time comparison
- Manual intervention and exception trends

## Example Dashboard Metrics

| Metric | Management Question |
|---|---|
| Median PR-to-PO days | How quickly are requisitions converted? |
| Median PO-to-GRN days | How efficiently are orders received? |
| Open PR ageing | What procurement backlog remains? |
| Long-lead transactions | Which transactions require investigation? |
| Exception rate | How significant are system/data anomalies? |

## Tools

Excel · Power Query · Oracle ERP · Pivot Tables · Data validation

> **Confidentiality note:** Examples are conceptual and contain no proprietary transaction data.
