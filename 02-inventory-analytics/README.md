# Inventory & Spare Parts Analytics

## Objective

Demonstrate a data-driven approach to evaluating inventory efficiency, ageing, stock utilisation and procurement controls.

## Analytical Areas

- Inventory ageing analysis
- Slow-moving and non-moving inventory
- Stock value exposure
- Consumption trend analysis
- Issue-to-available-stock ratio
- Purchase frequency analysis
- Reorder point assessment
- Supplier lead-time analysis
- PR-to-PO and PO-to-GRN cycle time
- Open requisition monitoring
- Duplicate item-code detection
- Exception-based testing

## Example KPI Set

| KPI | Purpose |
|---|---|
| Ageing >180 days | Identify potentially excess or obsolete stock |
| No issue in 12 months | Identify non-moving items |
| Issue ratio | Measure utilisation against available stock |
| PR-to-PO days | Assess procurement processing efficiency |
| PO-to-GRN days | Assess supplier and receiving lead time |
| Open PR percentage | Monitor procurement backlog |

## Excel Techniques

`XLOOKUP` · `SUMIFS` · `COUNTIFS` · `LET` · `FILTER` · `UNIQUE` · `AGGREGATE` · Pivot Tables · Power Query

## Recommended Management Outputs

1. Inventory ageing dashboard
2. Non-moving item register
3. Supplier lead-time dashboard
4. Procurement exception report
5. Reorder recommendation list
6. Monthly inventory KPI pack
