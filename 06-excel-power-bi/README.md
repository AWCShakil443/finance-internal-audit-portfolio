# Excel & Power BI Analytics

## Overview

A practical collection of techniques for transforming raw business data into reconciled analysis, exception reports, dashboards and management information.

## Excel Toolkit

- `XLOOKUP` for controlled lookups
- `SUMIFS` and `COUNTIFS` for multi-criteria analysis
- `LET` for structured formulas
- `FILTER` and `UNIQUE` for dynamic analysis
- `AGGREGATE` for filtered calculations
- Pivot Tables for summarisation
- Power Query for data preparation
- Conditional formatting for exception reporting
- Data validation and reconciliation checks

## Typical Audit Analytics

**Raw ERP data → Clean data → Mapping → Validation → Exception identification → KPI calculation → Management dashboard**

## Dashboard Concepts

- Inventory ageing
- Procurement lead time
- Audit issue ageing
- Wastage trend
- Cost variance
- P2P exception monitoring
- Monthly management KPI

## Design Principle

The objective is not simply to produce a dashboard. The analysis should answer a management question, identify exceptions and support an actionable decision.

> **Confidentiality note:** No employer-owned dashboards or datasets are published.
