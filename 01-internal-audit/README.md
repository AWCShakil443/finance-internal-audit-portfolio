# Internal Audit & Risk Assessment

## Overview

A professional framework demonstrating how internal audit work can be structured from risk identification through control testing, evidence evaluation, finding development and reporting.

## Core Approach

**Risk identification → Audit objectives → Process understanding → Control assessment → Test design → Data analytics → Exceptions → Root cause → Risk impact → Recommendation → Follow-up**

## Areas Covered

- Risk-based audit planning
- Process walkthroughs
- Internal Control Questionnaire (ICQ)
- COSO-based control assessment
- Control design and operating effectiveness
- Compliance testing
- Substantive testing
- Data-driven exception identification
- Root cause analysis
- Audit observation development
- Management recommendations
- Follow-up and remediation tracking

## Example Audit Finding Structure

| Component | Description |
|---|---|
| Condition | What was observed during the review |
| Criteria | Policy, SOP, control objective or sound practice |
| Cause | Why the exception occurred |
| Effect/Risk | Financial, operational, compliance or control exposure |
| Recommendation | Practical corrective action |
| Management Action | Agreed action and responsible owner |

## Risk Assessment Model

A simple risk score can combine **Impact × Likelihood × Control Weakness**. The model can be adapted to the organisation's approved risk methodology.
