# Wastage & Leftover Management Analytics

## Objective

Provide an analytical framework for identifying material wastage, reconciliation gaps, aged leftovers, disposal exposure and control weaknesses.

## Analytical Flow

**Input → Production consumption → Wastage generation → Godown receipt → Reconciliation → Storage ageing → Disposal → Sales / recovery**

## Key Tests

- Compare system-generated wastage with physical/godown receipts
- Identify quantity reconciliation differences
- Analyse wastage as a percentage of input
- Compare actual wastage against approved standards
- Identify aged leftover materials
- Analyse disposal quantity and recovery value
- Trace unusual adjustments and manual entries
- Review segregation of duties

## Example KPI Set

| KPI | Purpose |
|---|---|
| Wastage % | Measure production material efficiency |
| Reconciliation variance | Identify quantity differences |
| Aged leftover % | Highlight long-held materials |
| Recovery rate | Measure value recovered from disposal |
| Disposal exposure | Quantify potential financial loss |

## Management Value

The framework helps management identify process leakage, improve material accountability, strengthen reconciliation controls and reduce avoidable financial loss.

> **Confidentiality note:** Real operational data is intentionally excluded.
